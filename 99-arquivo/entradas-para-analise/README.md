# Entradas para análise

Pasta temporária para CSV, XLSX, JSON, TXT, PDF, prints e exports que ainda não possuem destino específico.

## Uso

- Colocar aqui somente uma cópia de trabalho.
- Informar a origem e a finalidade ao solicitar análise.
- Depois da análise, classificar a entrega em `00-contexto/`, `02-marketing/`, `03-edicao-ia/` ou outro destino aprovado.
- Não transformar automaticamente dados brutos em memória permanente.
- Não versionar segredo ou dado pessoal sem decisão explícita.
- Itens sem classificação permanecem preservados; nada é apagado automaticamente.

Este caminho substitui o `dados/` genérico do MazyOS.
